# ADR 0026: アルペジエーター overlay は「何を弾くか」を自分で持ち、「どう弾くか」をメイン画面と共有する

- 状態: 採用

## 決定

Guitar Articulation 画面のアルペジエーター overlay（`z`）は、素材にアルペジエーターを当てて鳴らし、
フレーズ全体の弾き方を素早く試す場所と割り切る。

- **overlay が自分で持つ（何を弾くか）**: 素材（MML / chord）、アルペジエーターの設定。
  設定 file に保存し、次に開いたときもアプリを起動し直したときも戻す。
- **メイン画面と共有する（どう弾くか）**: 行全体のルール（汚し・奏法）、アクセント、パラメータ、音色、effect chain。
  overlay で変えた値は閉じた後のメイン画面にも残る。
- **overlay では列ごとのルールを当てず、打つこともできない。**
- **overlay の操作は履歴に積まない。**

overlay を開いても閉じても、メイン画面の MML 欄と列ごとのルールは変わらない。

## 理由

- 素材を MML 欄と共有すると、overlay で選んだ素材が閉じた後の MML 欄に残り、MML 欄を書き換えた覚えのない利用者が混乱する。
- 列ごとのルールは素材の列番号に結びつく。素材を分けるなら列ごとのルールも分けるしかないが、
  overlay はフレーズ全体の弾き方を試す場所なので、列ごとのルールを持つ必要がない。
- 履歴は「MML とルール」の組で列が噛み合っている必要がある。overlay の状態を同じ履歴に積むと、
  メイン画面で選んだときに MML 欄が overlay の素材で置き換わる。overlay の状態は設定 file で戻せば足りる。

## 却下した案

- **overlay とメイン画面ですべてを分ける。** 汚し・奏法・アクセントを overlay で試しても
  メイン画面に持ち帰れず、試す場所としての役に立たない。
- **overlay 専用の履歴を持つ・履歴の 1 件に overlay の印を付ける。** 戻したいのは素材と設定だけで、
  設定 file の保存で足りる。

## 結果

- メイン画面で付けた列ごとのルール（スライドなど）は、overlay のアルペジオには効かない。
- overlay で変えた汚し・奏法・アクセントを次に起動したときにも残すには、メイン画面の状態として履歴か設定 file に残す必要がある。
