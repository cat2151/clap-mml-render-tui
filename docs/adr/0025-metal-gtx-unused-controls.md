# ADR 0025: METAL-GTX の効かない操作を Guitar Articulation 画面から出さない

- 状態: 採用

## 決定

METAL-GTX の説明書にある次の 4 つは、Guitar Articulation 画面の奏法・汚し・パラメータに出さない。

- Stop_Key（E-1 のラッチ中に vel ≤ 10 で打つ）
- 「C0 を短く打ち込んでリリース音を止める」
- CC31（`Picking_Micro`）。汚しからも送らない
- トリルに対する CC28

## 理由

どれも sfz の仕組み上、行の演奏経路で音が変わらない。

- Stop_Key: リリース層は `group=3 off_by=1`、Stop_Key のダミーサンプルは `group=2` なので、
  リリース音を切れない。
- 「C0 を短く」: C0（note 12）は Brush_Up の KS で、押しても何も鳴らない。
- CC31: 層が `volume=-100` + `gain_cc31=50` で、最大でも -50dB。居るのは Sus_Down のリリース・
  CC24 96〜111・F5〜E6 だけで、その条件でも相関 0.9987（対照どうしの揺らぎ 0.993 の内側）だった。
- トリルに対する CC28: `pitcheg_decaycc28=2` が trill の音程に効いていない。
  説明書の CC28 はユニゾンチョーキング用で、そちらには効く。

## 却下した案

- **説明書どおりに実装する。** 画面に音が変わらない操作が増えるだけで、効かない理由を利用者が探すことになる。

## 結果

余韻を切りたくなったら、Sus_Down のまま発音可能領域を弱く（vel 5 程度で）打ち込む方法が効く。
リリース音が 83.7dB 下がり、弱い音自体もほぼ聞こえない。この方法を使うルールは、余韻を切りたい場面が
出るまで作らない。
